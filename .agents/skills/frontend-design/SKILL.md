# Frontend Design

Approach this as the design lead at a small studio known for giving every client a visual identity that could not be mistaken for anyone else's. Make deliberate, opinionated choices about palette, typography, layout, micro-interactions, and motion tailored specifically for the product.

## Principles

1. **Ground it in the subject**: UniLib is an intelligent, high-caliber University Library Management system. Reflect the academic prestige, modern archival precision, tactile card-catalog warmth combined with high-tech clarity (deep navy/slate base, luminous emerald/indigo accents, crisp typography, glassy depth, sophisticated typography pairings).
2. **Typography**: Pair clean, modern editorial display fonts with razor-sharp geometric sans (e.g. Plus Jakarta Sans / Inter + Syne or Outfit or Instrument Sans) with intentional hierarchy, balanced line-heights, tracking, and tabular figures for numbers.
3. **Motion & Choreography**: Thoughtfully orchestrated animations — subtle stagger reveals, physics-inspired spring cards, smooth modal backdrop blur transitions, badge glow pulses on active statuses, smooth height expansions, interactive search state highlights.
4. **Structure is Information**: Clean elevation scales, glassy surface cards with subtle border gradients (`rgba(255,255,255,0.08)` / dark border accents), refined tag badges, visual status indicators (pulsing indicators for active holds/reservations), rich action bars, keyboard shortcut hints.
5. **Rich Interactive Moments**:
   - Quick search with instant filter tabs & clear counters
   - Modern glass stat widgets with sparklines/progress indicators & delta badges
   - Visual Book Spine & Color Badging with subtle tilt/hover transforms
   - Sleek modal dialogs with smooth backdrops and animated inputs
   - Interactive timeline / audit logs with status iconography
   - Refined toast notifications with progress bars and smooth enter/leave animations
   - Dark/Light polished modern theme with high contrast accessibility
