"Build a full-page animated 'book' landing page for a library management system, using HTML/CSS/JS (CSS 3D transforms, no video files). Sequence:

On load, a closed leather-bound book appears centered on a dark desk-toned background, medium size (~450px).
The book cover opens (1.5s), revealing the first page.
The whole book then scales up and repositions to fill the viewport, becoming the main site frame — the 'page' the user is now on.
Each subsequent page-turn (triggered by scroll, click, or a 'next page' arrow — not all automatic) reveals a new section of real site content: page 1 = hero/intro, page 2 = features, page 3 = how it works, page 4 = call-to-action/contact. Each page should look like an actual open book page (cream/parchment background, subtle paper texture, page-curl shadow at the turning edge) with real typography and layout for that section's content, not placeholder text.
Page turns take 0.8–1.2s each, with easing that mimics real paper — slight acceleration then a soft settle, not linear.
Maintain a warm, literary visual language throughout: leather/brass/parchment palette, serif display type, ambient dust-mote particles, soft directional lighting.
Fully responsive down to mobile (simplify the 3D page-turn to a slide/fade on small screens where 3D perspective looks bad).
Respect prefers-reduced-motion — skip straight to a static, scrollable version of the content for users who've disabled animation."
